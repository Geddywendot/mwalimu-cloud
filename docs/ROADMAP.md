# Roadmap
- **Cloud sync:** read attempts and review state from Supabase so progress follows the learner across devices.
- **More certifications:** AI-900, AZ-104, SC-900, and non-Microsoft certs through topic packs.
- **More languages:** Hausa, Yoruba, Amharic, Kinyarwanda, French. Community review flow.
- **Offline mode:** PWA with the cached explanations and question bank.
- **Teacher/cohort view:** study groups, shared leaderboards, weak-topic heatmaps for mentors.
- **Study planner:** weekly plan from exam date, available hours and weak areas.
- **Voice mode:** read explanations aloud for low-literacy and on-the-go learners.
- **Question review tools:** admin page to approve or edit flagged questions.
