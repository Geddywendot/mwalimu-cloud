# 3-minute demo script
**0:00 Problem (20s).** "Azure jargon felt abstract. I wished someone explained it with things I already know."
**0:20 Onboarding (15s).** Continue as guest, pick Kiswahili or English, set exam date.
**0:35 Explain (50s).** Open "Benefits of cloud services". Show the matatu analogy, the official definition beside it, and "where it breaks down". Toggle "Explain it simpler". Ask one follow-up.
**1:25 Quiz (50s).** "Quiz me on this", 5 questions. Answer one wrong on purpose and show why each option is right or wrong. Mention validation and the question bank fallback.
**2:15 Dashboard (30s).** Readiness score, domain chart, weakest topics, exam countdown. Open Revision to show the missed question returned.
**2:45 Impact (15s).** Same engine for AZ-104, AI-900 and more languages. Show the footer: unofficial.
